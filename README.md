# MadeForYou Studio — Website Portfolio

A responsive custom-website studio homepage with ten standalone portfolio concept projects.

## Structure
- `index.html` — MadeForYou homepage and project gallery
- `assets/madeforyou-logo.png` — studio logo
- `samples/` — ten standalone sample websites
- `.gitignore` — excludes local/editor/build files

## Portfolio transparency
The ten sample websites are original concept projects made to demonstrate design and implementation capabilities. Their fictional brands and scenarios are not represented as paid or commissioned client work. Replace illustrative content with verified client information before using any page for a real business.

## Deploy
For Cloudflare Pages, connect this repository and set the production branch to `main`, framework preset to `None`, build command to `exit 0`, and build output directory to `.`. For GitHub Pages, publish branch `main` from `/(root)`. Keep `index.html` at the repository root.
